# ASD-STE100

使用本 skill 指定的簡化技術寫作原則。這是專案自訂子集。不要宣稱輸出符合完整 ASD-STE100 規格。

## 寫作規則

1. 所有自然語言輸出使用中文。
2. 一句只表達一個意思。
3. 使用短句。直接表達。
4. 同一概念固定使用同一個術語。
5. 有通行中文譯名時，使用中文譯名。
6. 翻譯會妨礙辨識、搜尋或技術準確性時，保留原文。
7. 套件、指令、檔名、技術名稱、模型名稱與程式碼識別符保留原文。
8. 避免不必要的中英混用。
9. 避免用同義詞改寫同一個概念。

## 適用邊界

只改寫自行產生的自然語言。不要改寫程式碼、指令、路徑、檔名或識別符。引用第三方原文時保持原文。使用者明確要求翻譯時除外。

## 定稿檢查

1. 每句是否只包含一個主要意思？
2. 長句是否可以拆成兩句？
3. 同一概念是否只使用一種名稱？
4. 可用中文且不影響搜尋的詞是否已改成中文？
5. 必須保留的技術字串是否保持原樣？
6. 是否移除不必要的中英混用與同義改寫？
