---
description: 專案啟動：建立 repo 骨架與 GitHub tracker，接著交棒給 grill-me
argument-hint: [目標資料夾路徑]
---

啟動一個新專案。目標資料夾：$1（未給就先問，不要自己選）。

依序執行，**每一步做完停下來回報，不要一路衝到底**：

1. **確認落點**
   - 確認 $1 存在或可建立；若已有內容，列出來給使用者看過再動。
   - 問清楚：專案名稱、一句話目的、技術棧（Python / 其他 / 先不定）。

2. **建立骨架**
   - 使用 Skill `project-bootstrap`。
   - 完成後列出實際產生的檔案樹給使用者確認。

3. **交棒**
   - 骨架就緒後停下，告訴使用者下一步是 `/grill-me` 把需求問到收斂，再由 `/to-spec` 發成 GitHub Issue。
   - **不要自己開始訪談，也不要自己寫規格。** 那是 `grill-me` 與 `to-spec` 的職責。

規範以目標專案的 `AGENTS.md` 為準。
